## Branch 2: forecast-rate-match (throwaway forecasting)
  Name: forecast-rate-match
  Parent: production
  Purpose: What-if rate sensitivity analysis (throwaway — deleted after use)
  Lifecycle: created → scenario executed → results captured → deleted

  Scenario: "What if we raise the retention offer from 3.85% to 4.00%?"
  - Mutated lb_nba_recommendations on the forecast branch (safe — isolated from production)
  - Compared results:
    * 3.85% (production): predicted retained $9.9M, net value $8.6M
    * 4.00% (forecast): predicted retained $11.4M (+15%), net value $7.3M (-15%)
  - Conclusion: 3.85% is the optimal trade-off; 4.00% retains more but costs too much
  - Branch deleted after analysis (zero ongoing cost)

  Creation command:
  POST /api/2.0/postgres/projects/meridian-retention/branches?branch_id=forecast-rate-match
  {"spec": {"parent_branch": "projects/meridian-retention/branches/production", "no_expiry": true}}

  Deletion command:
  DELETE /api/2.0/postgres/projects/meridian-retention/branches/forecast-rate-match
